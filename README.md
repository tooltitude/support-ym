# Tooltitude for YAML

Tooltitude for YAML is a vscode extension providing productivity language services for YAML. The extension is being actively developed so stay tuned for new features.

## Features
NOTE: Features may have limitations. 

* Formatter
  * Control whether list item should be idented with `tooltitude.yaml.indentSeqs`
  * Control indent size with `tooltitude.yaml.indentSize`
* Outline (including breadcrumbs with the path to the current node)

## Data
We collect anonymous usage data. To opt-out of data collections, set the `telemetry.telemetryLevel` setting to `off` as directed by the Visual Studio Code documentation before installing the extension, or at any time after the installation: https://code.visualstudio.com/docs/supporting/faq#_how-to-disable-telemetry-reporting 
You could read more about our privacy policy here: https://www.tooltitude.com/privacy
